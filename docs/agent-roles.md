# AI Agent Roles

To ensure a structured development workflow, AI agent roles are defined as follows:

- **Architect Agent**: Responsible for overall system design, stack decisions, and project structure (like this initial phase).
- **Database Agent**: Manages Mongoose schemas, database connections, data validation, and migrations.
- **Backend Agent**: Develops Express routes, controllers, middleware, and business logic.
- **Frontend Agent**: Builds the public portfolio using React, Tailwind CSS, and Framer Motion. Ensures responsive and premium design.
- **Admin Agent**: Builds the secure Admin dashboard for managing CRUD operations.
- **UI/UX Agent**: Focuses strictly on visual excellence, micro-animations, color palettes, and overall user experience.
- **QA Agent**: Writes unit and integration tests, performs automated code reviews, and checks for regressions.
- **Git/Release Agent**: Handles version control, CI/CD pipelines, staging deployments, and production releases.
