# Target Features

## Public Portfolio
- **Hero Section**: Dynamic introduction with premium design.
- **About**: Developer background and philosophy.
- **Skills**: Visual representation of tech stack.
- **Experience**: Timeline of work history.
- **Projects**: Interactive gallery of past work.
- **Education & Certifications**: Academic and professional achievements.
- **Blogs**: Articles written by the developer.
- **Testimonials**: Endorsements from colleagues/clients.
- **Contact**: Form to send messages directly.
- **Resume**: Downloadable/viewable resume link.
- **Social Links**: Connections to GitHub, LinkedIn, etc.

## Admin Portal
- **Secure Dashboard**: Protected by JWT authentication.
- **Profile Settings**: Manage admin credentials.
- **CRUD Modules**: Interfaces to Create, Read, Update, and Delete for Projects, Experience, Skills, Education, Certifications, Blogs, and Testimonials.
- **Messages Viewer**: Read and manage contact form submissions.
- **Site Settings**: Update global site configurations (Hero text, links).
