# Development Workflow

1. **Phase 1: Planning (Current)**
   - Define stack, architecture, database, and roles.
   - Initialize git and project structures.
   
2. **Phase 2: Backend & Database**
   - Setup Node/Express server.
   - Connect to MongoDB Atlas (`portfolio` db).
   - Create Models and basic CRUD routes.
   - Secure Admin API routes.

3. **Phase 3: Admin Portal**
   - Setup Vite + React admin app.
   - Implement login and JWT storage.
   - Build CRUD interfaces for portfolio content.

4. **Phase 4: Public Portfolio Frontend**
   - Setup Vite + React frontend app.
   - Implement UI components using Tailwind & Framer Motion.
   - Fetch live data from Backend API.

5. **Phase 5: Testing & QA**
   - End-to-end testing of contact forms and data rendering.
   - Performance and SEO optimization.

6. **Phase 6: Deployment**
   - Deploy Backend to a cloud provider (e.g., Render/Heroku).
   - Deploy Frontend and Admin to static hosts (e.g., Vercel/Netlify).
